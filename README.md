MSCS 634 — Lab 1: Retail Sales Data Analysis
Purpose
Explore a synthetic 240-row retail sales dataset with Pandas and Matplotlib. The lab demonstrates data visualization, missing-value treatment, IQR outlier removal, data reduction, min–max scaling, discretization, and statistical analysis.
Files
- MSCS_634_Lab_1.ipynb: executable notebook, with screenshot checkpoints
- retail_sales_raw.csv: original synthetic data, including intentionally inserted missing values and outliers
- retail_sales_cleaned.csv: generated by running the notebook
- retail_sales_scaled.csv: generated by running the notebook
- screenshots/: add 11 screenshots following SCREENSHOT_GUIDE.md
How to run
1. Install Python packages: pip install jupyter pandas numpy matplotlib
2. Open the folder in Jupyter: jupyter notebook
3. Open MSCS_634_Lab_1.ipynb, select Python 3, and choose Run All.
4. Capture the requested screenshots after the relevant cells finish.
Insights
- Revenue varies by category because transaction price and quantity differ.
- Histograms and boxplots reveal intentionally inserted extreme values.
- A 14-day moving average smooths fluctuations in synthetic daily revenue.
- Correlation describes linear relationships but does not establish causation.
Decisions and challenges
- Filled missing quantities/prices with category medians to avoid mixing product price ranges.
- Removed quantity outliers using the 1.5×IQR rule, while retaining other unusual prices to demonstrate scaling sensitivity.
- Sampled 60% of the cleaned data with a fixed seed and dropped a less relevant rating column only in the reduction demonstration.
- Used synthetic data, so no real-world business conclusions are implied.
